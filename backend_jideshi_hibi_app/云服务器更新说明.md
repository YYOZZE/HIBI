## 更新流程（推荐）

### 方式 A：本机一条命令完成（需输入 2 次 root 密码）

在 **项目根目录**（`jideshi_hibi`）下执行：

```powershell
.\backend_jideshi_hibi_app\run_deploy_once.ps1
```

会先 scp 同步代码（提示输入密码），再 ssh 执行构建与重启（再提示输入密码）。完成后验证：<http://121.41.6.21:7861/docs>。

### 方式 B：分步执行

**1. 本机：同步代码到服务器**

在 **项目根目录**（`jideshi_hibi`）下执行：

```powershell
.\backend_jideshi_hibi_app\sync_to_server.ps1
```

- 会使用 **root@121.41.6.21**，将指定文件 scp 到服务器 **/root/jideshi_hibi_backend/**。
- 同步的文件包括：`api_only_app.py`、`hibi_auth_sync.py`、`hibi_payment.py`、`requirements.txt`、`Dockerfile`、`.env.example`、README、部署文档、`server_redeploy.sh` 等。
- 执行过程中会提示输入 **root 密码**（若已配置 SSH 免密则无需输入）。

**2. 服务器：构建镜像并重启容器**

SSH 登录后，在服务器上执行：

```bash
ssh root@121.41.6.21
cd /root/jideshi_hibi_backend
docker build -t jideshi_hibi_api .
docker restart jideshi_hibi_api
```

或使用脚本（会停旧容器、重建并启动，保留 data 卷）：

```bash
cd /root/jideshi_hibi_backend
bash server_redeploy.sh
```

**无 Docker 时（当前本 ECS）**：因镜像拉取超时，已在 **ECS 上**用 Python + venv 运行（非本机）。ECS 上启动：`cd /root/jideshi_hibi_backend && bash run_with_venv.sh`；已配置 systemd 服务 `jideshi-hibi-api` 开机自启。**阿里云安全组**须放行入方向 TCP 7861。**后端仅部署在 ECS，不要在本机运行后端。**

### 3. 验证

- 浏览器打开：http://121.41.6.21:7861/docs  
- 或 Flutter 应用使用当前 `api_config.dart` 中的 `authApiBaseUrl`（指向该地址）登录/同步，确认接口正常。

### 4. 登录失败排查（报错「连接被拒绝」）

- **含义**：本机连不上 `121.41.6.21:7861`，多为**服务器端**问题，不是 App 或 api_config 改错。
- **请依次确认**：  
  1. 端口是否监听：`ssh root@121.41.6.21` 后执行 `ss -tlnp | grep 7861` 或 `curl -s -o /dev/null -w "%{http_code}" http://127.0.0.1:7861/docs`，若返回 200 说明本机正常。  
  2. 阿里云安全组是否放行 **入方向 TCP 7861**：ECS 控制台 → 安全组 → 入方向规则，添加 7861。  
  3. 若用 Docker：`docker ps` 看 `jideshi_hibi_api` 是否 Up；若用 ECS 上 Python（systemd）：`systemctl status jideshi-hibi-api` 或 `ps aux | grep uvicorn`。  
- **处理**：Docker 时执行 `bash server_redeploy.sh`；systemd 时在 ECS 上执行 `systemctl start jideshi-hibi-api` 或 `cd /root/jideshi_hibi_backend && nohup bash run_with_venv.sh &`。

## 白板实时同步（多端同看）

- 电脑端对思维白板的操作会在大约 **1 秒内** 自动推送到云端（`/api/sync/push`）。
- 手机端（或另一台设备）打开同一项目的白板时，会 **每 2 秒** 拉取云端并刷新画布（`/api/sync/pull`），从而看到电脑端的改动。
- 无需改后端配置；确保电脑端与手机端均登录同一账号且 `api_config` 指向本 ECS（如 `http://121.41.6.21:7861`）即可。

## 可选：使用其他账号或主机

本机执行同步前可设置环境变量覆盖默认服务器：

```powershell
$env:SERVER = "root@其他IP"
.\backend_jideshi_hibi_app\sync_to_server.ps1
```

---

## 说明

- 同步脚本 **不会** 覆盖服务器上已有的 `.env`（只同步 `.env.example`），大模型等配置保留在服务器 `.env` 中。
- 用户与同步数据（含主题 settings）存储在服务器 **/root/jideshi_hibi_backend/data/**（由 Docker 挂载到容器 `/app/data`），重建容器不会丢失。
